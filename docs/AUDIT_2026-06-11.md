# Full Project Audit — 11 June 2026

> Four-track audit (data, methodology, documentation/claims, dashboard) run after dashboard
> deployment. Every CRITICAL/HIGH finding below was independently verified with reproduced
> numbers, not just asserted. Sensitivity re-runs live in `scripts/audit_sensitivity.py`.

## Verdict in one paragraph

The project's core is sound and its self-correction culture is genuinely good (LOCO demotion,
SDID negative result, Nordic-SC demotion all survive referee-level scrutiny). **The ETS
dose-response headline survives everything this audit threw at it, including corrected
treatment coding.** But the audit found three result-relevant problems: (1) `has_ets` miscodes
five countries as never-treated (Czechia, UK, Norway, Iceland, South Korea) — verified, though
the headline survives correction; (2) the Phase-4 sector-DiD "pre-trends pass (p=0.41)" claim
used a covariance-ignoring test — the correct joint Wald **rejects** (p≈0.004) and a pre-existing
covered-sector trend (−1.25%/yr) can explain the entire −19% endpoint, so the "clean ID ⭐" status
must be demoted; and (3) the deployed dashboard's interaction term makes the tax slider *increase*
predicted emissions whenever ETS ≥ ~$28, partly inside the un-warned slider region. Plus the
public-facing docs (README, DATA_DICTIONARY, skill file) still teach the exact bugs earlier
audits banned.

## Part 1 — Data audit

### CRITICAL

**F1. `has_ets` membership is wrong (verified).**
Cell 50 of `data_cleaning.ipynb` expands a hardcoded EU list, with two name mismatches and no
accession logic:
- **Czechia** (list says "Czech Republic" vs OWID "Czechia") → has_ets = 0 for entire panel.
- **United Kingdom** → has_ets = 0 always (was in EU ETS 2005–2020, UK ETS 2021). UK appears
  *tax-only* from 2013 when it was tax-on-top-of-ETS — directly contaminates tax-vs-ETS de-conflation.
- **Norway, Iceland** (EEA members of EU ETS from 2008) → has_ets = 0 always.
- **South Korea** ("Korea, Rep." fails the country filter) → KETS (2015, world's 2nd-largest ETS)
  never coded; Korea sits in the control pool.
- **Bulgaria, Romania** coded from 2005 (joined 2007); **Croatia** from 2005 (joined 2013) —
  Croatia has nonzero ets_price_only 2005–2012.

**F2. `has_tax` onsets are price-data artifacts, not implementation years (verified).**
`has_tax = (tax_price_only > 0)` and the WB price series starts late for several taxes:
Denmark coded 2007 (actual 1992), Finland 2000 (1990), Slovenia 2007 (1996), Estonia 2011 (2000),
Latvia 2014 (2004), Ukraine 2016 (2011), Portugal 2019 (2015), Mexico 2015 (2014), South Africa
2020 (2019). Treated countries sit in the control pool for years; staggered-DiD timing is biased.

**F3. `years_since_tax` is actually "years since first ANY pricing" (tax OR ETS)**, and is −1
(not 0) for untreated rows. It is in the validated confounder set under a wrong description.

## Part 2 — Methodology audit

### CRITICAL

**C-1. The Phase-4 capstone pre-trend test is miscomputed; the correct test rejects.**
The claimed "χ²(8)=8.3, p=0.41" reproduces exactly as Σ(bᵢ/seᵢ)² — a diagonal Wald ignoring
coefficient covariances. The full-covariance Wald on the identical committed spec
(`scripts/within_country_ets_did.py`): **χ²(8)=31.2, p=0.0001** (conservatively F(8,26)=3.90,
**p=0.004**). The pre-2005 covered-vs-uncovered gaps decline monotonically (+9.3% → +1.3%);
a pre-period covered-specific trend of **−1.25%/yr (p=0.093)** extrapolates to −21% by 2021 —
more than the entire −19% claimed endpoint. This is consistent with the project's own
covered-trend collapse result (covered:Pets → −0.0014, p=0.81), which was previously excused
*because* pre-trends "passed". **Demote the sector DiD from "clean ID ⭐" to the same epistemic
status as the tax (not separable from a pre-existing trend); fix the dashboard star row, the
event-study caption, and the FINDINGS_LOG capstone entry. Run Rambachan-Roth bounds (machinery
already exists from Phase 1).**

### HIGH

**H-1. EUA price endogeneity is never stated.** The dose engine regresses forward emissions on an
equilibrium market price; the 2008–13 crash was substantially demand-driven (the oversupply IS
the outcome feeding back). No statement of the identifying assumption anywhere. Mitigating: the
auditor's check shows the dose slope survives dropping 2005–2012 entirely (−0.0123, p=0.029) —
commit that check; state the assumption; cite carbon-policy-surprise IVs (Känzig 2023) as the fix.

**H-2. "Effective treated clusters ≈ 1" stands.** All EU countries share one EUA price path;
leave-one-country-out cannot address common-path confounding by construction. The overnight §3c
claim that LOCO "addresses the audit-flagged worry" is wrong and should be retracted; the
10-June "causally over-precise" framing was correct.

**H-3. Dashboard credible intervals are ~30–35% too narrow.** Overlapping 3-yr windows induce
MA(2) errors (measured within-country residual autocorr: lag1=0.56, lag2=0.20); the PyMC model
assumes iid Student-t. Posterior sd(b_ets)=0.0013 vs cluster-robust 0.0019. Cheapest fix: scale
posterior spread by the clustered/iid ratio when building `posterior.npz`.

### MEDIUM

- **M-1. In-sample ETS support tops out at $34.5, not €50.** The dose sample ends 2018 (t+3≤2021),
  so the "€47 recovery" is NOT in the estimation sample (in-sample recovery only to ~$16); the
  dashboard's extrapolation warning should start near $35, and the "crash→recovery" identification
  narrative needs correcting.
- **M-2. EUTL DiD**: 32% of installations exit (75% of exiters combustion) — survivor-only
  `log(verified)` makes −27% an intensive-margin estimate with composition drift; documented
  N (195k/17k) doesn't match the committed file (120,809/9,074).
- **M-3. Headline robustness checks live only in deleted scratch code** — and the one
  irreproducible-from-repo number (pre-trend p=0.41) is the one that's wrong. Commit a
  `scripts/robustness_suite.py` regenerating every cited number.
- **M-4.** `fossil_pct_filled` still live as control/moderator in `phase1_robustness_checks`
  (incl. the Oster covariate set), `phase2_multipolicy`, `causal_effects_library`;
  `outputs/effects_library.csv` is built on conflated treatment + the flag → deprecate.
- **M-5.** Asymmetric standard: tax's trend-collapse ⇒ "unproven", sector-DiD's trend-collapse ⇒
  excused via the (faulty) pre-trend pass. Corrected C-1 resolves this: harmonize the verdicts.

### LOW
$ vs € conflation throughout dashboard (data are US$); −19%/−27% are log-points labelled %;
era-stability claim is absence-of-evidence (post-2010 in-sample range only ~$5–17).

### Verified sound
Dashboard arithmetic (−9.4% @ €30 reproduces); full posterior plumbing (no point-estimate
shortcuts); LOCO honored (no covariate personalization); Phase-4 dose coefficient reproduces
exactly; GFC-drop check passes; SDID negative result methodologically correct; Nordic SC honestly
reported and properly demoted; Bayesian workflow (non-centered, PPC, LOO, prior sensitivity)
exemplary; country clustering everywhere; clean treatments used Phase-2 onward; ATT −0.15
consistently relabelled "combined pricing"; Kaya correctly demoted to accounting.

## Part 4 — Dashboard

### Correctness

- **A1 (HIGH). The interaction term makes the tax slider INCREASE predicted emissions whenever
  ETS ≥ ~$28** (marginal tax effect = b_tax + b_int·Pets flips sign at $27.7; default ETS=30).
  At ETS=$50, tax=$130 — inside both marginal thresholds so NO warning fires — the tax adds
  +7.1pp. At ETS=100, sliding tax 0→150 moves the headline from −31.4% to −5.1%. A user reads
  "adding a tax makes things worse"; the science says "unproven", not harmful. The bilinear
  `b_int` was fit where almost no country has both prices high; the guard checks each lever
  marginally, never joint support. Fix: joint-support warning + clamp/shrink the interaction
  out-of-support (or drop `b_int` from the displayed headline and show it as a sensitivity).
- **A2 (MEDIUM). Log-points displayed as percent** (no expm1): −9.4 shown vs −9.0% true at
  default; −31.4 vs −26.9% at ETS=100. Systematically overstates reductions, worst in the
  extrapolation zone.
- **A3 (MEDIUM).** Strict `>` thresholds (boundary values unwarned), no joint-support check,
  $/€ mixed labelling. Per M-1 the ETS warning should start ~$35, not 50.
- **A4/A5 (LOW).** "P(reduces)=0%" rendering at zero prices; no upper pins in requirements;
  `plt.close()` missing; prior sd = posterior mean (mild shrinkage toward 0 — conservative).
- Claim text: "substitutes, not complements" stated as fact though the project's own 10-June
  audit demoted it to suggestive (83-row cell); "era-stable" lacks a logged supporting number;
  ⭐ "clean ID — pre-trends pass" must be corrected per C-1.

### Verified correct
Boots clean (health 200); posterior keys/shapes correct; per-€30 scaling right; horizon
labelled right; 90% CI correctly Bayesian; confidence tags honest (in-sample support via
Mahalanobis distance, threshold = adopters' own p90); deploy is light (96KB npz, 4 deps);
